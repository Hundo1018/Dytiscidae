# Measured low-Reynolds-number section data: sources

Fetched 2026-11-16. Every number in the `*.csv` files is copied character for character
from the raw file named in its header; nothing is smoothed, interpolated, sorted or merged.
Generated by a script from the zips in `raw/` (row count checked against the count each
source run declares). All data here are wind-tunnel measurements; nothing is XFOIL or CFD.

## Converted files

Two kinds, because UIUC ran them separately:

- `<section>_Re<k>.csv`: **drag run**. `alpha_deg,cl,cd`. cd from a wake rake (momentum
  deficit), averaged over the spanwise stations (4 in Volumes 1-3, 8 in Volume 5); few
  points, roughly -5 to +11 deg, i.e. it stops near stall.
- `<section>_Re<k>_lift.csv`: **lift run**. `alpha_deg,cl,cm`. Force balance; goes past
  stall; **no drag**. Rows are in run order: alpha increasing and then decreasing, both
  branches kept (hysteresis).

The Re in a file name is the run's average Re rounded to 1000; the exact value is in the
header. The lift run and the drag run of one section are different runs at slightly
different Re and different alphas.

Notes on these files:

- `e387a` / `e387c` / `e387e` are three different physical models of the E387 (Volumes 1, 3, 5).
- `sd7037b` is model (B) from Volume 1; models A, C, D and re-runs of B are in the zips, not converted.
- `s1223_Re150k.csv` + `s1223_Re150k_run2.csv`, and `s1223_Re200k.csv` + `s1223_Re198k.csv`,
  are each one polar that UIUC took as two runs (low and high alpha). There is no S1223
  drag run at Re 60k. `s1223v5_*` are Volume 5 lift runs of a different S1223 model.
- `goe417a` (Goe 417a) and `bw3` (BW-3) are the thin cambered sections; `cr001` (CR-001) is
  a thin hand-launch-glider section, not a plate.
- `flatplate_uiuc_*`: flat plate, t/c 3.10 %, baseline leading edge (Volume 5). **Lift and
  moment only; UIUC published no drag for it.** This is the only tabulated measured
  flat-plate section data obtained.
- Volumes 1 and 2 were re-reduced by UIUC in 1997/98; the files here are that re-reduced
  version, so they differ slightly from the printed Volume 1/2 tables.

## Data-quality caveats

- UIUC drag is a wake-rake measurement and is given only up to about stall; lift is a
  force-balance measurement. A post-stall drag value does not exist in these files.
- Below about Re 100k the UIUC drag varies along the span (the per-station values are in
  the raw files); the tabulated cd is their spanwise average.
- UIUC's own cross-checks are the E387 models (their comparison is against NASA LTPT data);
  model accuracy and tunnel turbulence matter at Re 60k, so different models of one
  section differ (compare `e387a`, `e387c`, `e387e`).
- Bruining's drag is from a balance on a plate between end plates, and his clean-plate
  cd_min (0.085 at Re 60k, 0.06 at 100k) is on that basis; it is not a wake-rake figure.
