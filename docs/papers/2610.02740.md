## 2. Problem and setting

LLM agents trained with RL use only *retrospective* signals (verifier reward, PRM score, hindsight-teacher distillation): the gradient depends on the realized outcome but never on what the agent *expected* at action time ("hindsight trap", §2.3, Eq. 2). Consequence claimed: a confident success and a lucky success get the same update, and an overconfident failure is penalized like an aware failure; accuracy rises but overconfidence is not fixed. The setting is language-model policies (OLMo-3-7B-Instruct, gpt-oss-20B) with token-level policy-gradient / on-policy-distillation losses, on (a) single-turn verifiable tasks and (b) a multi-turn LLM-simulated tutoring "personal agent". PH adds a self-prediction of outcome and uses the prediction–outcome disagreement to upweight loss on those rollouts. It is a **loss-reweighting plug-in**, not a new RL algorithm. Nothing in the paper concerns robotics, physics simulation, or quality-diversity search.

## 3. Method

### 3.1 Formal setup (§2.1, VERIFIED)
- Policy π_θ; at step t state s_t, action a_t ~ π_θ(·|s_t). Evaluator R sees privileged context c_t that the agent does not: r_t = R(s_t,a_t,c_t) ∈ {−1,0,+1}; y_t = 1[r_t > 0] ∈ {0,1} (Eq. 1). Single-step: T=1, c_t = ground-truth reference. Multi-turn: c_t = s_{t+1}.
- Base loss ℓ^base_t(θ): any retrospective method, treated abstractly (GRPO, OPD, Combined; formulas in 3.5).

### 3.2 Prospective self-evaluator (§3.1, App. C.4, F, VERIFIED)
- Same network, same θ, prompted differently (no extra head, no extra trainable parameters). After the policy emits a_t and **before** the verifier/PRM scores it, issue an extra generation: "do you believe your answer is correct?" with the reply constrained to exactly one of `+1` (confident correct), `-1` (believe wrong), `0` (unsure). Parsed from a `\boxed{}` field per §3.1 (the single-step prompt in App. F.1 literally requests one of +1/0/−1; the boxed parse is how §3.1 describes it — minor inconsistency, UNKNOWN which the code does).
- It sees only (s_t, a_t); never c_t or the outcome. Task-routed prompt templates (math, mcq, tool_use, code, default) wrap a common ternary instruction (App. F.1).
- z_t = majority vote of M i.i.d. samples. Strict majority of {−1,+1} wins; a tie or all-unparseable → z_t = 0 (App. C.4). z=0 rollouts get weight exactly 1 (neutral class).
- Single-turn: M=1, max_new_tokens=128, temperature 0.6, top-p 0.95, unparseable → 0. Multi-turn: M=3, max_new_tokens=256 (App. D.1, D.2, Tables 4–5).

### 3.3 Calibration taxonomy (Table 1, VERIFIED)
Cells over (z_t, y_t): CS (+1,1) confident success; OF (+1,0) overconfident failure; US (−1,1) underconfident success; AF (−1,0) aware failure. Diagonal = calibrated, off-diagonal (OF, US) = miscalibrated.

### 3.4 Update rule (§3.3, Eq. 4–5, VERIFIED)
```
ξ_t   = 1[(z_t, y_t) ∈ {OF, US}]               # discrete gate
ℓ^PH_t = (1 + α·ξ_t) · ℓ^base_t(θ)             # ξ_t is a stop-gradient constant
```
- α ≥ 0 is the **only PH training hyperparameter** (plus M, plus a weight clip in single-turn). α=0 recovers the base method exactly. Default α=1.
- Weight w_t ∈ {1, 1+α}. Single-turn clip w_t ∈ [0.5, 2.0] "as a safety net" (App. D.1, rarely active at α=1). Multi-turn: no clip.
- **Continuous gate (multi-turn, App. C.3 Eq. 30):** z̄_t = mean of M ternary samples ∈ [−1,1]; ξ^cont_t = ½·|z̄_t − r_t| ∈ [0,1]; w_t = 1 + α·ξ^cont_t ∈ [1,1+α]. Reduces to the discrete gate at the corners. Flag `SURPRISE_MODE ∈ {discrete, continuous}`. Note the continuous gate compares z̄ with r_t ∈ {−1,0,+1} (PRM score), not y_t.
- Where the weight is applied: per-rollout loss (single-turn, multiplying the SDPO per-rollout reverse-KL); per-turn combined advantage A^comb_t before the PPO surrogate (multi-turn), broadcast over all tokens of the response (App. C.1, D.2). GRPO's group std is computed on the **original** rewards, not the weighted loss.
- No gradient flows through the predictor/ξ. The predictor is never trained with an explicit calibration loss; any calibration gain arrives via shared parameters (claimed mechanism, not isolated by an experiment — see 5).

### 3.5 Pseudocode (Algorithm 1, App. C.2) and base methods (App. C.1)
```
for prompt x_b in batch:
  for each step/turn t of the rollout:
     a_t ~ π_θ(.|s_t)
     z_t^(m) ~ p_eval_θ(.|s_t,a_t), m=1..M ; z_t = majority(z_t^(1..M))   # extra fwd passes, no c_t
     receive c_t, y_t from env/verifier
     ξ_t = 1[(z_t,y_t) in {OF,US}]
     ℓ_t^PH = (1 + α ξ_t) ℓ_t^base(θ)
θ ← optimizer_step(θ, ∇ Σ_{b,t} ℓ_t^PH)       # ξ_t stop-gradient
```
Base methods: GRPO A_t = (r_t − r̄)/(σ_r+ε) over G rollouts of the same query (Eq. 26); OPD token advantage A_{t,j} = log π_θ(a_tj|prefix,s_t,c_t) − log π_θ(a_tj|prefix,s_t) (Eq. 27); Combined A = w_rl·A^GRPO + w_opd·A^OPD with w_rl = w_opd = 1 (Eq. 28). SDPO single-turn: correct-solution mode; one verified-correct rollout inserted as privileged context for the EMA teacher; per-token reverse KL, top-K=100, EMA rate 0.05, IS clip 2, thinking disabled.

### 3.6 Theory (VERIFIED as stated; the authors call it motivation, not guarantee)
- Prop. 1 (law of total variance): Var(y|s,a) = E[Var(y|s,a,c)|s,a] + I*(s,a), I* = Var(E[y|s,a,c]|s,a) ≥ 0 — an aleatoric term plus a "privileged-information gap" that no action-time predictor can resolve (LUPI framing). Standard identity.
- Prop. 2: E[ℓ^PH] = E[ℓ^base] + α·R(θ), R = E[ξ·ℓ^base] ≥ 0 (linearity).
- Prop. 3: R(θ) = c(θ)·M(θ), exact tower-rule identity; M = Pr[ξ=1] = binary Brier score of z'=(z+1)/2 vs y; c = E[ℓ^base | ξ=1]. OFR = Pr[OF]/Pr[z=+1] is reported as an OF-conditional proxy for M (assumes Pr[z=+1] stays stable and Pr[US] small; paper says both held empirically).
- "Self-extinguishing": as ξ→0, w→1, R→0, so PH and the base method share fixed points. Calibration-alignment of the gradient direction depends on a "uniform-base-loss" assumption (G, Limitations).

### Ablations (§4.2, App. D.3, E)
- **Random reweight:** same (1+α) multiplier and same *per-step total weight* as PH, applied to a uniformly random subset of size ⌊p_t·N⌋ (p_t = PH's surprise fraction on the same data). Isolates selection from added gradient mass. Result: Science Q&A OFR 33.3 vs 34.2 (≈none); Tool Use 36.3 vs 40.7.
- **Failure-only reweight:** (1+α) on all y=0 (cells OF∪AF) — differs from PH in including AF and excluding US; tests whether z adds information beyond y. Science Q&A OFR 25.0 (PH 20.9; ~60% of PH's *drop*, text says "most"), surprise 24.4 vs 21.8; Tool Use 39.3 (PH α=1.0: 33.6) — failure-only barely moves OFR there.
- **α-sweep:** single-turn {0.1,…,2.0} (Table 6, Fig. 3, 6, 7); multi-turn {0.5,1,2}; cell dynamics qualitatively unchanged across α, α=2.0 noisier / highest round-to-round variance.
- **Self-extinguishing dynamics (Fig. 2, 7):** OF cell shrinks, CS grows, mean weight decays toward 1 as pass rate rises (qualitative figures).
- PAcc rises ~30%→~80% under PH on Science Q&A while SDPO plateaus ~73% (§4.2, Fig. 3 — read from text).
- Not ablated (INFERRED from absence): shared vs separate predictor; M>1 single-turn; discrete vs continuous gate head-to-head; predicting with a frozen/external predictor; weighting by magnitude of surprise vs binary.

## 5. Limitations

Stated by the authors (App. G, §3.4, §4.3):
- High α (≥2) causes gradient-norm spikes / instability, esp. long multi-turn; predictor can collapse to constant z=−1 (observed at α=2.0).
- Calibration-alignment analysis rests on a uniform-base-loss assumption; "quantitative motivation rather than pointwise guarantee"; the calibration link is "diagnostic".
- Extra compute: M forward passes per step (~6% sync single-turn, ~0% async multi-turn).
- Depends on self-model quality; early signals noisy if the base model is badly calibrated.
- Scope: verifiable single-turn tasks and a math-tutoring agent only; horizons ≤48 turns; subjective/creative tasks, sparse delayed rewards, long-horizon agents, graded PRM scores untested; evaluator quality not independently characterized (future work).
- Broader impact: reliance on verifier/PRM quality (errors get amplified); "deceptive calibration" risk of avoiding hard tasks.

INFERRED limitations:
- **Evidence strength.** No variance/CI in any table despite "3 seeds"; many accuracy differences are 1–3 points, and Random reweighting (no signal) also moves accuracy and OFR on both datasets. Capability gains look small and α-nonmonotone; multi-turn α=2.0 sometimes below baseline. The strongest claim supported by the data is OFR reduction on Science Q&A (and a weaker one on Tool Use).
- **Metric circularity.** Calibration metrics (OFR, surprise) are measured with the same shared-parameter predictor being trained, with no external-judge check of predictor accuracy; OFR can fall by predicting −1 more often (they admit this at α=2.0). "Calibration" here is a binary-hit rate, not ECE/Brier on continuous confidence. A drop in Pr[z=+1] mechanically lowers OF.
- **Mechanism untested.** The claim that calibration improves "as a byproduct via parameter sharing" has no control with a separate predictor; the stop-gradient reweighting does not itself train z. The failure-only control matches PH on Science Q&A OFR gains partly, suggesting much of the effect is outcome-weighting of failures.
- Positive-weight-only scheme: weights ≥1, so it effectively raises LR on a data-dependent subset; interaction with grad-clip (1.0 single-turn) and Adam normalization not analysed.
- Requires a **binary (or ternary) retrospective label per rollout** and a rollout-local prediction before seeing it; a base rate near 0 or 1 makes OF/US cells degenerate (e.g. Science Q&A early pass rate ≈23–26%).
- Results are for LLM-token-level losses; no evidence for continuous-control or non-LM predictors.

## 6. Touchpoints for Dytiscidae — SPECULATIVE (not from the paper)

The paper's mechanism is: (action-time prediction of a binary outcome) vs (realized outcome) → multiplicative ≥1 weight on that sample's loss. None of its experimental evidence transfers directly; the shared-parameter predictor premise does not match this project (the critic is a separate model). Each item names the precondition.

1. **Surprise-weight the shared PPO's per-segment loss using the Tier-1→Tier-2 gap.** Weight (1+αξ) on PPO samples where the learned critic (or Tier-1 score) predicted "success/competent" but the later Tier-2/Tier-1.5 label says failure (OF), or the reverse (US). Precondition: a *binary* outcome label (e.g. mission leg success or air competence >0.15) that is reliably available for the same sample at update time, a prediction made before the label, and a base rate not near 0 (mission success is ~1%, so OF vs AF counts and US would be extremely lopsided; threshold-set per the project's "from measured distribution" rule). Also needs the project's critic to be actually fitted (arch45 critic was inert per memory).
2. **Exploit/leak detector for Tier-1 scores.** Overconfident-failure rate of Tier-1 (Tier-1 says competent, Tier-2 says zero) as a telemetry metric and as a per-design flag for selection or re-scoring priority — analogous to how passive-motion leaks (falling, drifting) were discovered. Precondition: Tier-2 evaluated on enough designs to estimate OFR per medium; an agreed binary cut at each tier. This is a diagnostic use and needs no change to the loss.
3. **Weighting critic training samples (or choosing which designs get Tier-2 spend) by prediction–reality gap.** Upweight designs where the critic's per-medium residual prediction missed by the most, an active-learning / hard-example weighting. Precondition: Tier-2 budget per generation is small (it is expensive); selection bias from only verifying high-predicted designs must be handled (missing OF cases for designs never verified). The paper's Random-reweight control is the template for a fairness check (same total weight, random subset).
4. **MAP-Elites emitter/operator credit.** Surprise-based prioritization of which parents or variation operator outputs to retain or re-evaluate (prediction error in outcome space as a novelty/curiosity signal). Precondition: a predictor of descendant score made before evaluation; the paper itself positions this as related to intrinsic-motivation work but did not test it.
5. **Annealing property as a sanity check, not a feature:** the "weight→1 when predictor and verifier agree" behaviour could be monitored as a convergence signal for the critic. Precondition: the critic's ternary/binary output defined per medium; with 1% mission base rate it will not self-extinguish soon.
- Not applicable / low value: the LM-specific parts (prompting the same network for self-assessment, majority vote over generations, OPD/SDPO teachers). The project's policy is not an LM; a "same-parameters" prospective head would be a new architectural change (e.g. an auxiliary critic head on the PPO net) whose benefits the paper did not isolate.
- Risk (INFERRED): upweighting ≥1 and high α destabilised training in the paper; PPO here is already contention-limited and the project has repeatedly found sparse signals dominated by gate artifacts, so any use should first pass the still-machine and mutation checks.
