## 1. Citation

- Title: NeutronGym: Physics-Graded Neutron Instrument Design for LLM Agents
- Authors: Lijie Ding, Changwoo Do (Neutron Scattering Division, Oak Ridge National Laboratory)
- arXiv: 2610.03631v1 [cs.AI; also physics.ins-det], submitted 2 Oct 2026
- Code/data: https://github.com/ljding94/NeutronGym (Reproducibility Statement; I did not open the repo). Release claims: environment package, benchmark tasks, per-episode evidence, training records and step telemetry, trained LoRA adapters with checksums.

## 2. Problem and setting (VERIFIED, abstract/§1)

The paper asks whether LLM agents can do physics (not recall it) when designing a scientific instrument, graded only by simulation. Setting: neutron-scattering instruments in the McStas Monte Carlo ray tracer; an instrument is a text file of placed, parameterized components. Agents act through 22 validating MCP tools. The authors identify three evaluation problems: reward can be satisfied in unintended ways (nine failures found in their own reward/task generator), contamination (4 of 7 pilot episodes retrieved the reference file through permitted tools), and degeneracy (a generated task family can be solved by one fixed answer or one prompt-copying rule). Contributions: (a) an admission protocol of "no-model probes" for procedural tasks; (b) the environment plus a 16-task benchmark (McStasBench); (c) RL results showing a trained 8B model beating an untrained 32B on four gated families, with analyses of what the gain is. They explicitly claim no novelty in the training method (GRPO + LoRA). Every scored task fixes the instrument layout; no task asks for topology choice (§1, §6).

## 3. Method

This is an evaluation/training environment, not a new optimizer. Components below.

### 3.1 Environment (§3.1, App. B) — VERIFIED
- Agent never writes the file or sees a shell; 22 MCP tools wrap McStasScript; 374 shipped components can be looked up. Every mutating call is validated against component metadata at call time (unknown component/parameter refused with nearest valid suggestion). Raw .instr import/export remains as an escape hatch. In benchmark mode the example-retrieval and file-load tools are disabled.
- Speed: mcrun costs ~2.4 s/run in translation+compilation regardless of ray count. They compile each family once (keyed on a hash of comment-stripped source) and execute each instance as a parameter assignment on the binary: 33 ms median at 1e5 rays, ~30 rollouts/s/CPU core.
- Agent sees per-monitor summary statistics, not raw arrays.

### 3.2 Reward ladder (§3.2) — VERIFIED
Four levels checked in order:
- L1 (static, no simulation): action assigns exactly the family's free parameters, all finite, within bounds, and passes the family's geometric specification checks.
- L2: a short run at reduced ray count completes.
- L3: the environment's protocol run (ray count and seed fixed per instance, never agent-chosen) leaves >= 500 events in the graded monitor. Maximization families additionally require observables inside band constraints relative to the baseline and intensity within the phase-space bound. Matching families carry neither.
- L4 (physics): maximization families: r = FOM / (baseline x target_fraction), pass iff r > 1 strictly (grading is deterministic at the fixed seed, so resubmitting the baseline scores exactly 1 and is not an improvement). Matching families: every matched observable within tolerance of the hidden-design target; r = tolerance / worst relative error; r > 1 passes; noisier observables get wider tolerances.
- Reward: 0.25 per level through L3, then once L3 holds, 0.75 + 0.25 * min(r, 2), whether or not r > 1 is met, capped at 1.25. "Rises with depth, then with margin". Gate-then-score structure.
- Partial per-level credit below L3 means reward is nonzero for any run that merely compiles and runs (0.25-0.75 floor region); L3-clearing designs start at 0.75.

### 3.3 Phase-space bound (§3.2, App. J) — VERIFIED
Passive neutron optics cannot raise phase-space density, so monitor intensity I <= Phi * A * Omega * dLambda (source brilliance x monitor area x solid-angle acceptance x wavelength band). An action above 1.10x the bound fails L3. Derived only for the two maximization families (guide: etendue bound at the divergence monitor; SANS: conservation bound through the pinhole chain). The 1.10 margin was calibrated on the guide family at 1e5-1e6 rays: legitimate optima read 0.93-0.99 of the bound; a stress test of 56 corner/boundary/random-extreme actions gave max legitimate utilization 1.016 and no false flag. The bound is evaluated only above a statistics floor (finding 5 in Table 6: a legitimate action read 1.14x on a 250-event monitor, 0.99 at 10x the rays). All four matching families (where every training number is measured) carry no bound.

### 3.4 Task families and calibrated targets (§3.3, App. I Table 8) — VERIFIED
- A family = fixed layout; numeric parameters split into instance context (given to agent) and design knobs (agent sets). An instance is a deterministic draw from (family, split, index). Held-out split draws at least one context parameter from an interval disjoint from training (a regime shift, not a fresh seed).
- Six families: 2 maximization (guide divergence, SANS collimation), 4 matching (guide match, SANS match, TOF chopper, bender). Matching targets are observables of a hidden per-instance design at the protocol seed; instances whose targets the baseline already meets are discarded.
- Target calibration: constraint-filtered search (30 random valid samples, then local pattern search) scored exactly as an agent is scored, at the protocol seed (common random numbers); target = 0.85 x best FOM found. An earlier undersized-baseline version let untrained models pass 80-93%.
- Free parameters / tolerances (Table 8): guide match: entrance/exit width in [1,9] cm, m in [1,3], sample 0.1-1.5 m after exit, match spot size and divergence within +/-5%, held-out guide length 12.5-16 m (train 6-12). SANS match: two pinhole radii in [1,20] mm, +/-1.5% (chosen after sweeping the untrained 8B: 45.3% at 3%, 24.7% at 1.5%, 18.0% at 1%). TOF chopper: frequency 20-60 Hz, phase, opening angle, +/-5%. Bender: radius of curvature 40-550 m, aperture 2-8 cm, m in [1.5,4], mean wavelength +/-0.25%, spread +/-1%, hidden design must cut 25-85% of incident band.
- Tolerances were fixed by measuring the untrained model before training, on slices not used for checkpoint selection.

### 3.5 Admission gate (no-model probes) (§5.1, App. H, Tables 6-7) — VERIFIED
Before any pass rate is read as capability, a family faces:
1. Best fixed action: grid over free parameters + the baseline + every probed instance's own calibrated solution applied to all other instances + local refinement around the best candidate. (A 5-level grid reported SANS best-constant at 12% while a between-grid-points constant passed 51%, so candidate coverage matters.)
2. Best rule that reads quantities stated in the prompt (including hand-coded physics inversions).
3. Concentration of a trained policy's own passing designs (diagnostic, read by hand, no threshold).
Decision: a family fails if the baseline passes anywhere, if a copy-type rule succeeds, or if the one-sided 95% Clopper-Pearson upper bound on the best constant's pass share exceeds 20% (the 20% level is a choice; one admitted family clears it by ~2 points). A physics inversion that passes is reported as a reference arm, not a disqualifier. Sample size matters: against the 20% ceiling n=25 certifies only at <=1/25 passes, n=150 at <=21/150, n=300 at <=48/300; a 5/25 observation had earlier been wrongly called a pass; best-constant share fell from 20% at n=25 to 13.3% at n=150 (maximizing over many candidates inflates small samples).
Results (Table 7, 150 held-out instances): guide divergence 13.3% fixed / 96.3% readout rule (rejected); SANS collimation 14.0% / 56.0% (evaluation only); bender v1 10.7% (rejected on concentration); guide match 4.0% / 27.7% physics inversion (admitted); SANS match 12.7% / 3.3% (admitted); TOF chopper 2.7% / 0.0% (admitted); bender 8.0% / 12.7% (admitted).
Concentration (distinct designs among passes): guide match 225/230, TOF chopper 138/140, SANS match 115/133, bender 63/227 (both observables follow from one cutoff wavelength), rejected bender v1 42/141 (one design reused 17 times). Authors state a class-level criterion is an open problem.

### 3.6 Nine reward failures (App. G Table 6) — VERIFIED
1. Unconstrained flux maximization collected 672 n/s of direct beam past the beamstop (upper limit on beam width cannot catch it). Fix: two-sided band constraints relative to baseline pattern.
2. Nelder-Mead in the simulator ignored parameter bounds (a width escaped to 2.1 m). Fix: classical baselines are bounds- and constraint-filtered ensembles.
3. Winner's curse: best of 30 noisy evaluations fell below its own target at a fresh seed. Fix: re-verify any selected optimum.
4. Matching monitors by event count graded an agent's diagnostic monitor as its detector (correct instruments failed 3/6). Fix: match by role and position.
5. Phase-space check false flag on a 250-event monitor. Fix: evaluate bound only above statistics floor.
6. SANS family: maximal pinholes with no model passed 8/25 held-out instances (one at 11,992x target; unscattered beam leaked around the beamstop); 22 of 35 cached optima were leaks. Fix: geometric direct-beam check at L1.
7. One fixed action passed about half of held-out instances (guide 52.3%, SANS 51.0%, n=300). Fix: per-instance specs/baselines, calibration under common random numbers, the gate.
8. Repaired guide family passed the constant-policy gate yet a rule copying two prompt-stated limits passed 96.3%. Fix: report a no-model readout-rule baseline beside every training result.
9. First bender family passed gate at 10.7% but 24.7% of instances had a hidden design that filtered nothing (any transparent design solved them). Fix: require hidden designs to alter the observable (cut 25-85% of band); diagnose by design concentration.

### 3.7 Training (§5.1, App. K) — VERIFIED
- Base: Qwen3-8B, thinking disabled in chat template. LoRA rank 32, alpha 64, on q,k,v,o and gate,up,down projections. Merged adapter served via vLLM for evaluation, checked against training tokenization.
- Training states: every turn of the untrained model's episodes over 300 training instances, failures included (~2,810 states for guide match; 8,592 for pooled three-family set). A state = full dialogue up to a decision point; the model is trained on the single action taken there (a turn-level, not episode-level, formulation).
- GRPO per update: 8 states x 8 completions per state, temperature 1.0, 96 new tokens max per action, prompts truncated at 6,000 tokens. Each completion scored by the ladder via a simulation server. Advantage = (r - mean)/std within the group of 8; groups with std < 1e-3 contribute nothing. One gradient step per sampled batch (strictly on-policy, no PPO clipping described), on token log-probs; KL term is the per-token k3 estimator against the frozen base; gradient norm clip 1.0; AdamW; seed 20260916.
- Schedule: stage A 120 updates at lr 1e-5, KL weight 0.02; stage B 100 more updates at lr 3e-5, KL weight 0.01; 220 updates total, ~3.5 h on one A100. Ablation and joint runs use the identical schedule.
- Imitation baseline (rejection-sampling style): same LoRA shape on the untrained model's own successful episodes, lr 1e-4, 2 epochs, ~32k tokens/step, sequences up to 8,192, prompt masked from loss, seed 20260913; truncated dialogues dropped.
- Evaluation: 300 held-out instances (150 for out-of-range split), temperature 0, 10-turn budget, paired exact McNemar against the baseline on the same instances; tolerances not tuned on the evaluation slice.
- Not specified / UNKNOWN: batch-level number of rollouts total (8x8 per update x 220 = 14,080 completions implied, INFERRED), the exact system prompt, how the "simulation budget ~10 sims / 33 evals" maps (Table 12 says classical optimizers get 10 simulations, with 30 simulations as a separate row; the HTML-summary figure "~33 evaluations" is not supported by the PDF).

### 3.5 What is learned vs fixed
Learned: LoRA weights of the policy only. Fixed: simulator, reward ladder, tools, task families, tolerances, targets. No learned reward model, no critic, no judge.

## 4. Experiments

### 4.1 McStasBench (§4, Table 1, App. M Table 10) — VERIFIED
16 scored tasks from 12 published instruments, 5 classes; T1 reproduce-from-spec, T2 improve (target 80% of the way to a classical optimum), T3 open design (unscored). Controls: memorization probes, 2 never-released held-out instruments, perturbed variants kept only with a pair proof, sandbox + transcript audit. Protocol: pass@1, temperature 0, 50-turn cap, one episode per task and arm; one-shot arm = whole .instr in one completion, no tools. Table 1 (Loop seen / 1-shot seen / Loop held-out of 2 / 1-shot held-out):
- Claude Sonnet 5: 5 / 7 / 2 / 1 (dominant failure: L1 does not compile)
- Claude Haiku 4.5: 4 / 4 / 2 / 0 (L4)
- Gemini 3.6 Flash: 4 / 6 / 2 / 1
- Gemini 3.5 Flash-Lite: 2 / 1 / 1 / 0
- Llama 4 Maverick: 0 / 2 / 0 / 0
- Qwen3-32B: 3 / 0 / 2 / 0
- Qwen3-8B: 1 / 0 / 1 / 0
No per-model difference significant; Wilson 95% CI on 7/16 is 23-67%. Loop vs one-shot counts do not differ for any model (Fisher p >= 0.22). No agent met the T2 improvement target. No episode retrieved a reference. A T1 pass is effectively an exact reproduction (32 of 39 scored seen-tier passes match the reference on every observable exactly).

### 4.2 Procedural families, RL (§5.2, Fig. 2, Table 11) — VERIFIED
Guide match, 300 held-out instances: untrained 8B 11.3% (34/300); untrained 32B 11.3% (Table 12) (the 32B is "no stronger than the 8B there"; an HTML-page summary claiming 68.3% for the 32B contradicts the PDF Table 12); GRPO 8B seed 1 76.7% (230/300), seed 2 69.0% (207/300); two seeds differ p=0.043 (Fisher). Paired vs untrained 8B discordant 213 vs 17; vs untrained 32B 208 vs 12.
Three further gated families (single seed each), trained 8B vs untrained 32B on a selection-free slice (Fig. 2): SANS match 44.3% trained (51.0% on the checkpoint-selection slice) vs untrained 8B 26.0%; discordant 89 vs 43; TOF chopper and bender discordant 116 vs 12 and 125 vs 29; all p <= 8e-5. Gains over untrained 8B range 18-65 points. Table 11 (slice 300-599) specialists: guide 76.7, SANS 51.0*, TOF 46.7, bender 75.7; untrained 8B 11.3 / 22.3 / 2.0 / 23.0.
Joint multi-family LoRA (220 updates split across families): joint4 63.7/43.3/56.3/55.0; joint3 67.7/24.0/55.0; joint3rep (same config, new seed) 34.0/19.3/2.3 (TOF at the untrained 2.0%). Telemetry: share of sampled groups with any reward spread was ~4.5/8 in joint3 vs 2.1/8 in the second stage of joint3rep; mean reward stayed flat 0.77-0.83, so the failure was silent in training reward.

### 4.3 Analysis / ablations (§5.3, Table 2, Table 9, Table 12) — VERIFIED
Guide match, 300 held-out instances unless stated:
| Arm | Pass | delta vs GRPO 76.7 |
|---|---|---|
| Coordinate descent from baseline, agent budget (10 sims) | 13.3% | -63 |
| Coordinate descent from random start, same budget | 14.3% | -62 |
| Coordinate descent from baseline, 3x budget (30 sims) | 73.7% | -3 |
| Hand-coded optics inversion, no search | 27.7% | -49 |
| Optics inversion then coordinate descent, 10 sims | 81.0% | +4 (paired discordant 59 vs 46, p=0.24, not significant) |
| Nelder-Mead 10 sims / 30 sims | 2.7% / 40.0% | |
| Random search 10 / 30 | 7.3% / 20.0% | |
| Frontier zero-shot (first 100 instances): Claude Sonnet 5 / Gemini 3.6 Flash | 99% / 98% (trained model 76/100 on the same 100) | +22 |
- Reward ladder removed (pass/fail only, all else identical): 16.7% (50/300), discordant 196 vs 16, p=1.5e-40. Mechanism: median 0.33 of 8 sampled groups per update had any reward spread with pass/fail vs 5-7 with the ladder. Caveats stated by authors: one seed vs one seed; the same gradient-starved signature appeared with the ladder in the collapsed joint run, so the ladder is necessary not sufficient; pass/fail removes level and margin credit together so the 60 points cannot be apportioned.
- Tolerance stress: tightening +/-5% to +/-2% takes ratio trained:untrained from 6.8x to 18x (67% vs 3.7%). Out-of-range split (n=150): 45.3% vs 17.3% untrained, p=7e-7.
- Grading-seed fragility: re-grading all 230 passing designs at three fresh seeds, 80% hold at every seed, 88% of re-runs hold, 5% fail at all three (boundary-edge).
- Transfer: on the rejected guide family (prompt-copying passes 96.3%), guide-match model reaches 34.0% vs 18.0% untrained (discordant 76 vs 28, p=3e-6); rejections before simulation fall 73 -> 20. Authors read this as the habit "propose valid geometry, then refine", not design skill.
- Training length: checkpoints at 120/220/340 updates score 50.0/73.0/56.7% on another held-out slice while training reward keeps rising.
- Imitation of own successes (Table 9, pre-repair task, not comparable to RL rows): all turns 40.3% -> 31.3% (discordant 20 vs 47, p=0.0013); passing turns only 52.3% (= one fixed action's 52.3%, delta 0); SANS 31.0% -> 27.0%; harder-target SANS 8.3% -> 1.0%.
- Not recall: every untrained episode reaches L3, so the gain is all at L4; no 8B/32B policy passes guide match or TOF chopper on the first turn (SANS match 2/133; bender 18/227); 225 of 230 passes are distinct designs; the two seeds' pass sets overlap (agreement 0.68).
- Pre-registered: the first supervised run, matched-compute, frontier and ablation experiments; the rest exploratory. Unadjusted p-values; only p < 1e-3 treated as confirmatory. A feedback-label defect before 2026-09-16 (per-turn FOM shown as a fraction of target but labelled as relative to baseline) affects the supervised runs and the rejected-guide GRPO run; none were re-measured.

## 5. Limitations

Stated by the authors (§6, App. A, §5.3) — VERIFIED:
- 16 tasks at one episode each cannot rank models or separate scaffolds; held-out instruments are simpler than the seen median and not facility-validated.
- No scored task asks for a topology choice; families set 2-3 parameters of a fixed layout and every training number lives there; the procedural side is narrow; matching families were built after shortcuts were found; simulation idealized (ideal monitors, no background, gravity off).
- Probe suite is incomplete by construction: bounds what one fixed answer can pass, not a class; admitted a quarter-degenerate bender family. Concentration is a diagnostic, not a gate.
- Training evidence exploratory: one seed per configuration except two; joint configuration bimodal across seeds (so single-seed specialists' confidence is bounded); 8B on 2-3 parameter tasks; below frontier models; matched at equal budget by a physics-seeded search; weaker outside training ranges; 5% of passes fail at all three re-grade seeds; more training hurts.
- Thinking-enabled Qwen arms were not run (limits the "past an untrained 32B" comparison); one API model behaved differently on two providers; temperature-0 batched decoding is not bit-reproducible.
- Frontier models zero-shot vs trained model's 300 training instances; frontier comparison unpaired on the first 100 instances.
- Authors used Claude Code extensively to write the harness, and evaluate models from the same provider (disclosed).

INFERRED limitations:
- The domain (LLM agent writing tool calls, numeric parameters of a fixed layout, ~30 ms evaluations, deterministic seeded grading) differs sharply from quality-diversity search over a body-graph genome with 100+ s generations. The transferable content is the evaluation/reward-hygiene practice, not the training result.
- The "dense partial credit is load-bearing" claim rests on one ablation pair at one seed, on LLM turn-level RL. The mechanism (reward spread inside a sampled group) is specific to group-normalized policy gradients.
- Partial credit makes any compiling/running action worth 0.25-0.75; the authors can afford this because the L4 pass is separately defined. In a setting where intermediate levels can be reached by passive motion, level credit could itself reward the wrong thing (the project's own history).
- The 20% gate level is a typed constant ("a choice"); no principled derivation. Gate power depends on candidate coverage and n, as the authors' own SANS grid example shows.
- Targets set at 0.85x best-found search value mean "passing" is bounded by search quality; the hidden-design matching tasks are solvable by construction (a solution exists).

## 6. Touchpoints for Dytiscidae — SPECULATIVE

None of these is validated by the paper for QD/MAP-Elites or rigid-body flapping robots. Each lists the precondition.

1. Formalize the "still machine" check as a pre-registered no-model gate (probes: actuators held still / constant gait / a readout rule that reads the genome or prompt-like descriptors / every elite's gait applied to every other body), decided on a one-sided Clopper-Pearson upper bound rather than the observed share. Directly matches the project's iron rule from Designing a Measurement #1/#6/#7 (each leak found by hand after a score paid a passive machine). Precondition: a fixed probe-policy set per medium and score, an n large enough for the bound to have power (paper: n=25 certifies only <=1/25 at a 20% ceiling), candidate coverage that includes between-grid constants, and a pass-share ceiling set from the measured distribution, not typed (project rule on thresholds).
2. Concentration / distinctness diagnostic on the sparse successes. Among the ~1% of evaluations with nonzero mission (or air competence > 0.15), count distinct designs vs passes, and check whether successes collapse to one reused design or one class (paper: 42 distinct in 141 passes exposed a degenerate family the fixed-answer gate missed). Precondition: a distance on genome or descriptor space for "distinct"; read by hand, not as a gate (paper does the same).
3. Reward-spread telemetry for the shared PPO policy and the critic: log, per update/batch, the fraction of sampled groups or rollout batches with within-group reward spread above a floor (paper: 0.33/8 under pass/fail vs 5-7/8 with the ladder; 2.1/8 flagged a silent collapse while mean reward looked fine). Precondition: PPO rollouts organized into comparable groups (same body/state), or a per-batch advantage-variance counter. Cheap to log; diagnostic only. Relevant because ~1% nonzero mission implies most batches may carry no signal.
4. Level-resolved (gate-then-score) reward for the sparse mission signal: depth credit (feasible, runs, structural, physics) then margin, with the physics level gated by the commanded-phase checks. The project already has rungs, Tier-0 feasibility and gated scores, so the paper mainly supports keeping/extending depth credit for the shared PPO reward. Precondition: each lower level must be unreachable by a held-still or passive machine (otherwise depth credit pays the leak); the paper's ablation is one seed on LLM RL, so treat as a hypothesis to test as an A/B on PPO signal-fraction, not as established.
5. Reference-free physical ceiling as a gate: the paper's I <= Phi A Omega dLambda is a conservation bound, margin 1.10 calibrated on legitimate optima (0.93-0.99, max 1.016 on 56 stress actions), evaluated only above a statistics floor. A Dytiscidae analogue would be a bound on thrust, lift or energy (e.g., actuator-disc or power bound on rotors; aerodynamic power bound; energy-height accounting for the glider case in rule 7) applied to quasi-steady solver outputs to reject exploits of the fluid solver. Precondition: a derivable bound for the quantity, a stress set of extreme-but-legitimate designs to place the margin, and a statistics-floor analogue for short segments.
6. Re-verify selected optima at a fresh seed (winner's curse, finding 3) and grade-seed fragility counts (80% of passes hold at 3 re-seeds, 5% fail all) when promoting elites to Tier-2; and in the paper's evidence, selecting a checkpoint on one slice and reporting on another. Precondition: Tier-1/Tier-2 evaluations deterministic given a seed and cheap enough to repeat on the small set of elites; project already has a separate eval path, so this is mostly a reporting convention.

Not recommended from this paper: its imitation-vs-RL result and joint-training instability are specific to LLM turn-level RL; no direct bearing on MAP-Elites variation operators. INFERRED weak link: "on-policy training on decisions from every state, failures included" echoes the project's critic problem (all 4 Tier-2 successes dropped by a gating label), but the paper trains no critic.
