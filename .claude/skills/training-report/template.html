    10 · Best design of the run

    Not in this report, and why

    This run's telemetry does not contain the following, so they are absent rather than estimated:
    • Q / V value traces — only the value loss is logged, not the value estimates themselves.
    • Gradient norm — not recorded. grad_steps and clipfrac are the nearest available proxies and clip fraction is charted.
    • Action distribution — actions are not logged per step. Reward by segment tag is charted instead, which is the closest thing the run recorded.
    • Learning curves across seeds — this run is a single seed (20260901). One seed is not a curve family and drawing it as one would be a lie.
    • Win rate / death cause — the failure taxonomy in §7 is the equivalent; there is no win condition, only a graded mission fraction.
